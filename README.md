# DrinkHelper 智慧飲料小幫手

## 專題功能
- 飲料推薦（依口味偏好提供規則式推薦）
- 飲料菜單、成分與過敏原資訊查詢
- 客製化點餐（甜度、冰塊、配料、備註）
- SQLite 訂單資料儲存
- 訂單進度查詢
- 常見問題助手（FAQ）
- 顧客評價與意見回饋
- 店家管理展示頁（更新訂單狀態、查看回饋）

## 執行方式
建議使用 Python 3.10 以上版本。

1. 解壓縮專案資料夾。
2. 開啟終端機並切換到專案資料夾。
3. 建立虛擬環境（建議）：
   - Windows：`python -m venv venv`
   - macOS：`python3 -m venv venv`
4. 啟用虛擬環境：
   - Windows：`venv\\Scripts\\activate`
   - macOS：`source venv/bin/activate`
5. 安裝套件：`pip install -r requirements.txt`
6. 啟動網站：`python app.py`
7. 開啟瀏覽器進入：`http://127.0.0.1:5000`

店家管理展示頁：`http://127.0.0.1:5000/admin`

## 課堂展示流程
1. 首頁依照口味進行飲料推薦。
2. 展開飲料卡片查看成分與過敏原資訊。
3. 填寫客製化點餐表單並送出。
4. 記下訂單編號，在訂單查詢頁查看狀態。
5. 進入 `/admin` 將訂單狀態改成「製作中」或「可取餐」。
6. 回首頁填寫顧客意見，再到管理頁查看回饋。

## 注意事項
這是課堂專題原型，不含線上金流、簡訊通知、真實 AI API 或正式帳號權限。`/admin` 目前沒有登入保護，僅供本機展示，不應直接部署到公開網路。飲料成分及過敏原為示範資料，實際使用前必須由店家核實。
